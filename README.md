# G·HOT 档案 · 日报与周报

「爆料革命」公开信息的每日与每周记录。每期含当日/当周要点，以及互动量最高的十条帖子全文。

每期两种格式，内容相同：`.md` 在本页面直接可读；**`.txt` 下载后 Windows / macOS / iPhone / Android 双击即开，便于转发给他人**。每份报告顶部与各索引页都有 .txt 的下载入口。
